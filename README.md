# FormShift — Pyrus form migration demo

Независимый демонстрационный прототип для переноса значений между полями формы Pyrus. Показывает, как можно подготовить массовое обновление задач, не меняя данные в рабочем аккаунте.

## Что умеет

- сопоставляет старые и новые поля по числовым ID;
- проверяет обязательные значения, email и положительную сумму;
- пропускает уже совпадающие значения;
- показывает ошибки по каждой задаче;
- выгружает **только план** обновления в JSON с `dry_run: true`.

Встроенный `sample.json` содержит вымышленные данные. Можно загрузить свой JSON той же структуры; файл обрабатывается в браузере. Приложение **не подключается к Pyrus и не выполняет запись**. Не загружайте реальные клиентские данные в публичный репозиторий.

## Запуск

Нужен Node.js 20 или новее. Дополнительные пакеты не нужны.

```powershell
npm start
```

Откройте http://127.0.0.1:4190. Для проверки движка: `npm test`.

## Как адаптировать к реальной форме

1. Получить ID формы, ID или коды полей и примеры задач с разрешения владельца Pyrus.
2. Получить структуру формы через `GET /forms/{form-id}`, записи через `GET /forms/{form-id}/register`.
3. Согласовать типы, обязательность и правила преобразования полей; протестировать на копии формы.
4. После утверждения плана отдельно добавить авторизованный режим записи через `POST /tasks/{task-id}/comments` с `field_updates`, журналом операций и защитой от повторного применения.
5. Для настоящего бота отдельно согласовать обработчик событий и правила валидации в рабочем процессе.

Экспортируемый JSON — демонстрация структуры плана, **не готовый запрос для массового запуска**. Авторизация и работа с реальной формой не реализованы.

Документация Pyrus: [формы](https://pyrus.com/en/help/api/forms), [задачи и обновление полей](https://pyrus.com/en/help/api/tasks), [коды полей](https://pyrus.com/en/help/integration-development/field-codes).
